# Web Dissect - Privacy Policy

This repository hosts the official privacy policy for **Web Dissect**, an open-source accessibility auditing Chrome extension.

## Overview
Web Dissect values user privacy. All web page scans and accessibility checks run locally within your browser tab, and no user data or scan results are transmitted to external servers.
